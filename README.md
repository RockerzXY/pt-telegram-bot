# Telegram бот PT_START — Ansible

## Описание
Этот репозиторий содержит код телеграм-бота для удалённого мониторинга и управления внешним хостом. 
В данной ветке реализовано автоматизированное развёртывание с помощью Ansible. Playbook-ами производится установка, настройка и обновление компонентов (бота, базы данных и репликации) на удалённых серверах.


## Требования
  - Подготовить **два хоста** для развёртки
  - Ansible (версия 2.9 или выше)
  - Доступ по SSH к удалённым серверам


## Структура проекта
- `ansible.cfg` — конфигурационный файл Ansible, определяющий настройки для выполнения плейбуков..
- `init.sql` — SQL-скрипт для инициализации базы данных.
- `inventory.yaml` — файл инвентаря, содержащий информацию о хостах и переменных для развертывания.
- `playbook-tg-bot.yaml` — ansible playbook для автоматизации процесса развертывания телеграм-бота.


## Установка и запуск с помощью Ansible
Для развертывания бота выполните следующие шаги:

1. **Подготовьте хосты** — установите ansible, настройке пользователей для корректной работы.

3. **Клонируйте репозиторий с веткой `ansible`:**
   ```sh
   git clone https://github.com/RockerzXY/pt-telegram-bot.git -b ansible
   cd pt-telegram-bot
   ```
   
4. **Отредактируйте `inventory.yaml` файл** — укажите необходимые переменные окружения (см. [Конфигурация](#конфигурация)).

5. **Запустите плейбук:**
   ```sh
   ansible playbook -i inventory.yaml playbook-tg-bot.yaml
   ```
   Ansible автоматически установит и настроит все необходимые компоненты на указанных серверах согласно прейбуку.
  

## Конфигурация
Проект использует переменные окружения, которые необходимо задать в `.env` файле:

| Переменная          | Описание |
|---------------------|------------------------------|
| `TOKEN`            | Токен телеграм-бота |
| `WORKDIR`          | Рабочая директория для деплоя |
| `GIT`              | URL репозитория с кодом бота |
| `RM_HOST`          | Хост удалённого сервера |
| `RM_PORT`          | SSH-порт удалённого сервера |
| `RM_USER`          | Пользователь удалённого сервера |
| `RM_PASSWORD`      | Пароль пользователя удалённого сервера |
| `DB_HOST`          | Хост PostgreSQL |
| `DB_PORT`          | Порт PostgreSQL |
| `DB_USER`          | Пользователь БД |
| `DB_PASSWORD`      | Пароль пользователя БД |
| `DB_DATABASE`      | Название базы данных |
| `DB_REPL_HOST`     | Хост реплицируемой БД |
| `DB_REPL_PORT`     | Порт реплицируемой БД |
| `DB_REPL_USER`     | Пользователь репликации |
| `DB_REPL_PASSWORD` | Пароль пользователя репликации |
| `POSTGRES_VERSION` | Версия PostgreSQL |
